## Mục tiêu
Sau task này mở `http://localhost:3000` thấy vỏ app đúng thiết kế và trang chủ báo API "đang chạy" hoặc "không kết nối được".

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.4 (AC4.2, AC4.3, AC4.4), 5, 7
- Thiết kế: `docs/Agentic RAG UI.html` (vỏ app: sidebar, header, avatar góc dưới trái)
- Skill: `fe-ui-design` (sidebar, header 56px có nút thu gọn + Breadcrumb, khung `h-dvh overflow-hidden`, chỉ vùng nội dung cuộn), `fe-nextjs-typescript`.
- Nền tảng từ M0-T04: token, shadcn (`button`, `tooltip`, `separator`, `dropdown-menu`, `sheet`, `skeleton`), next-intl, next-themes.
- API: `GET ${NEXT_PUBLIC_API_URL}/healthz` → 200 `{"status":"ok"}` (M0-T02). CORS cho `http://localhost:3000` (M0-T05).

## Acceptance criteria
- **AC1**: `app/(app)/layout.tsx` dựng vỏ app: sidebar trái thu gọn được (trạng thái nhớ bằng cookie hoặc localStorage), header cao 56px có nút thu gọn sidebar + Breadcrumb, vùng nội dung `min-h-0 flex-1 overflow-y-auto`. Menu sidebar chỉ có "Trang chủ". Trên mobile sidebar thành `Sheet`. (SPEC AC4.2)
- **AC2**: Góc dưới sidebar có nút mở menu gồm: đổi ngôn ngữ vi/en, đổi giao diện Hệ thống/Sáng/Tối. Đổi không reload trang. (SPEC AC4.2)
- **AC3**: Trang chủ `(app)/page.tsx` (route `/`) hiển thị tên ứng dụng và thẻ "Trạng thái API": loading (skeleton) → "Đang chạy" (gọi `/healthz` 200) hoặc "Không kết nối được" (lỗi mạng/không 200) kèm nút "Thử lại". Gọi phía client bằng `fetch` trong `lib/health.ts`, timeout 3 giây. (SPEC AC4.3)
- **AC4**: Không chuỗi hardcode; mọi text từ `messages/{vi,en}/shell.json`, `home.json`. (SPEC AC4.4)
- **AC5**: a11y: nút chỉ có icon có `aria-label`, focus ring thấy rõ, điều hướng được bằng bàn phím (Tab tới menu, Enter mở, Esc đóng). (SPEC mục 7)
- **AC6**: Test Vitest + Testing Library: trang chủ ở 3 trạng thái loading/đang chạy/không kết nối (mock `fetch`); nút thu gọn sidebar đổi trạng thái; render đúng chuỗi vi và en.
- **AC7**: Dark mode không có chữ chìm vào nền (kiểm tay, chụp màn hình sáng/tối đính vào PR).

## Yêu cầu bảo mật (từ threat model)
- **SR-14** (Medium): gọi API qua `web/lib/env.ts` (M0-T04), không đọc `process.env` trực tiếp.
- **SR-15** (Low): chỉ hiển thị trạng thái suy ra từ HTTP status qua key i18n; không render body thô, không `dangerouslySetInnerHTML`; fetch dùng `AbortSignal.timeout(3000)` và `cache: "no-store"`. Test: body `{"status":"<img src=x onerror=alert(1)>"}` → DOM không có `img`; fetch treo → "không kết nối được".
