## Mục tiêu
Sau task này `make -C api test-integration` và `make -C workers test-integration` chứng minh khung chạy đúng với Postgres/Redis thật của `make up`.

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.2 (AC2.3, AC2.5), 4.3 (AC3.1, AC3.2), 4.7 (AC7.1)
- Skill: `testing-standards`. Ở M0 chạy trên stack `make up` (127.0.0.1:5432, :6379) thay vì testcontainers để giữ nhẹ; ghi chú điều này trong file test.
- Go test tích hợp dùng build tag `integration`; Python dùng marker `integration` (đăng ký trong `pyproject.toml` là thuộc M0-T03 — nếu chưa có thì dùng `conftest.py` trong `workers/tests/integration/` để đăng ký).

## Acceptance criteria
- **AC1 (api)**: Given stack `make up` healthy, When chạy binary/handler thật với config từ `.env`, Then `/readyz` trả 200 `{"status":"ok"}`.
- **AC2 (api)**: Given `DATABASE_URL` trỏ cổng không có Postgres (vd 127.0.0.1:1), Then `/readyz` trả 503 với `failing` chứa `postgres`, phản hồi trong ≤ 1,5 giây; body không chứa chuỗi lỗi kết nối hay DSN.
- **AC3 (api)**: Given server đang xử lý 1 request chậm (handler test), When gửi SIGTERM/gọi shutdown, Then request đó hoàn tất và server thoát trong ≤ 10 giây. (Nếu không làm được qua API công khai của M0-T02 thì ghi lý do và bỏ, không sửa code sản phẩm.)
- **AC4 (workers)**: Given Redis thật, When chạy `python -m rag_worker` như subprocess, Then trong 10 giây stdout có dòng JSON `msg=ready`; gửi tín hiệu dừng (Ctrl+C/SIGINT) → thoát mã 0 trong ≤ 10 giây.
- **AC5 (workers)**: Given `REDIS_URL` trỏ cổng không có Redis, Then thoát mã 1 trong ≤ 10 giây và output không chứa mật khẩu trong URL.
- **AC6**: Target `test-integration` trong `api/Makefile` (`go test -tags=integration ./test/integration/...`) và `workers/Makefile` (`uv run pytest -m integration tests/integration`). Test tích hợp **không** chạy trong `make check` (unit only).
- **AC7**: Test bỏ qua (skip) có thông báo rõ khi stack chưa chạy, không fail mơ hồ.

## Yêu cầu bảo mật (từ threat model)
- **SR-2** (Medium): `/readyz` 200 và worker `ready` khi đúng mật khẩu Redis; sai mật khẩu → `/readyz` 503 `failing` chứa `redis`, worker thoát 1.
- **SR-7** (High, kiểm tích hợp): output worker khi lỗi kết nối không chứa mật khẩu.
- **SR-8** (Medium): trỏ cổng chết → body 503 chỉ chứa tên phụ thuộc, không DSN/lỗi kết nối.

## Lệnh kiểm tra

```
make up && make -C api test-integration && make -C workers test-integration && make check
```
