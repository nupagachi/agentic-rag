## Thiết kế bắt buộc (để wave 1 chạy song song không đụng file chung)
- Root `Makefile` **ủy quyền** cho Makefile con: `check-api: ; $(MAKE) -C api check`, tương tự `check-workers` → `workers/`, `check-web` → `web/`; `dev-api|dev-worker|dev-web` → target `dev` của Makefile con.
  - Nếu `<app>/Makefile` chưa tồn tại thì in `skip: <app> chưa có` và trả mã 0 (để main xanh giữa các wave). Khi file đã có thì lỗi phải làm fail.
  - `sec` cũng ủy quyền: `gitleaks detect` ở root + `$(MAKE) -C <app> sec` nếu có.
- Hợp đồng Makefile con (ghi vào README mục "Thêm ứng dụng/area"): mỗi app có target `check`, `dev`, `sec`; tùy chọn `test-integration`.
- Target root tối thiểu: `help` (mặc định), `env`, `up`, `down`, `reset`, `dev-api`, `dev-worker`, `dev-web`, `check`, `check-api`, `check-workers`, `check-web`, `sec`. `help` tự sinh từ comment `## mô tả` trên mỗi target.
- `deploy/.env.example` khai báo sẵn biến cho cả 3 app để wave 1 không phải sửa (nhãn "CHỈ DÙNG CHO DEV"):
  - `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `POSTGRES_PORT=5432`, `REDIS_PORT=6379`, `REDIS_PASSWORD`
  - `API_ADDR=127.0.0.1:8080`, `DATABASE_URL`, `REDIS_URL`, `LOG_LEVEL=info`, `CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000`
  - `WORKER_REDIS_URL` (hoặc dùng chung `REDIS_URL`), `WORKER_LOG_LEVEL`
  - `NEXT_PUBLIC_API_URL=http://127.0.0.1:8080`
- `make env`: copy `deploy/.env.example` → `.env` ở gốc nếu chưa có (không ghi đè).
- `make up`: `docker compose -f deploy/docker-compose.dev.yml --env-file .env up -d --wait`.
- `make reset`: hỏi `y/N` rồi `down -v` và `up`.

## Yêu cầu bảo mật (từ threat model)
- **SR-1** (High): mọi `ports` trong compose ghi host IP `127.0.0.1` tường minh. Thêm target kiểm (gọi từ `make sec`): `docker compose config` → số `published:` bằng số `host_ip: 127.0.0.1`.
- **SR-2** (Medium): Postgres dùng `POSTGRES_PASSWORD` từ `.env`, không `trust`; Redis chạy `--requirepass ${REDIS_PASSWORD}`. Thêm `REDIS_PASSWORD` vào `.env.example`; `REDIS_URL` dạng `redis://:<mật khẩu>@127.0.0.1:6379/0`.
- **SR-3** (High): image pin tag patch cụ thể (`postgres:16.x`, `redis:7.2.x` với x ≥ 11, CVE-2025-49844); target kiểm mọi dòng `image:` có số phiên bản và không `latest`.
- **SR-5** (High, phần root): `make dev-web` ủy quyền cho `web/Makefile`; không tự chạy `next dev` thiếu `-H 127.0.0.1`.
- **SR-16** (Medium): `mise.toml` pin phiên bản chính xác cho runtime và tool (`gitleaks`, `govulncheck`, `golangci-lint`, `air`, `uv`), không `latest`. README/Makefile không có `curl … | sh`.
- **SR-17** (Medium): `.gitignore` chặn `.env`, `.env.*` (trừ `.env.example`), `deploy/secrets/`, `*.pem`. Dòng đầu `.env.example` ghi "CHỈ DÙNG CHO DEV", giá trị dạng `dev_only_change_me`. `make env` không ghi đè. Allowlist gitleaks (nếu cần) chỉ cho `deploy/.env.example`.
- **SR-18** (Medium): `make sec` fail-closed: không tiền tố `-`, không `|| true`; thiếu tool thì lỗi kèm hướng dẫn cài; gitleaks chạy `--redact`.
- **SR-20** (Low): `make reset` chỉ xóa volume của compose project này (`docker compose -p <project> ... down` kèm cờ xóa volume), không `prune`; compose có `name:` cố định.
