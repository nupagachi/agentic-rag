## Mục tiêu
Sau task này `make dev-web` chạy Next.js tại `http://localhost:3000` với design token sáng/tối, i18n vi/en, shadcn và bộ lint/test đầy đủ — sẵn sàng để M0-T06 dựng vỏ app.

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.4 (AC4.1, AC4.4), mục 7 (i18n, a11y)
- Kiến trúc: `docs/Kiến trúc.md` mục 3 (Next.js)
- Thiết kế: `docs/Agentic RAG UI.html` (màu, font, khoảng cách)
- Skill: `fe-nextjs-typescript`, `fe-ui-design` (token trong `web/app/globals.css` với `@theme`, dark mode dưới `.dark`, font Geist/Geist Mono qua `next/font`).
- Message i18n tách theo tính năng: `web/messages/{vi,en}/<feature>.json`.
- Biến `NEXT_PUBLIC_API_URL` đã có trong `deploy/.env.example` (M0-T01).

## Acceptance criteria
- **AC1**: Next.js 15 App Router, TypeScript `strict: true` (+ `noUncheckedIndexedAccess`). `npm ci && npm run dev` chạy. (SPEC AC4.1)
- **AC2**: Tailwind 4 + token màu/radius/font theo `fe-ui-design`, có bộ token `.dark`. shadcn khởi tạo (`components.json`) với tối thiểu `button`, `tooltip`, `separator`, `dropdown-menu`, `sheet`, `skeleton` (đủ cho vỏ app ở T06).
- **AC3**: next-intl cấu hình vi (mặc định) và en; chọn ngôn ngữ lưu cookie, **đổi không reload trang** (gợi ý: không đặt locale trong URL, đọc cookie ở request config, dùng `router.refresh()`). Ghi lựa chọn routing trong PR. (SPEC AC4.2 phần i18n)
- **AC4**: `next-themes` với `attribute="class"`, hệ thống/sáng/tối; không nháy màu khi tải (`suppressHydrationWarning`).
- **AC5**: ESLint: `next/core-web-vitals`, `typescript-eslint` strict, rule cấm chuỗi giao diện hardcode trong JSX cho `app/**` và `components/**` (trừ `components/ui/**`). (SPEC AC4.4)
- **AC6**: Vitest + Testing Library + jsdom, `tests/setup.ts`; có 1 test mẫu render provider với message vi/en.
- **AC7**: `web/Makefile`: `check` = `npm run lint && npm run typecheck && npm test -- --run && npm run build`; `dev` = `npm run dev` (nạp `NEXT_PUBLIC_API_URL` từ `../.env`); `sec` = `npm audit --audit-level=high`. `make check-web` từ root xanh. (SPEC AC1.3, AC5.3)
- **AC8**: `app/page.tsx` tạm thời có thể redirect hoặc để trống hợp lệ; trang chủ thật thuộc M0-T06.

## Yêu cầu bảo mật (từ threat model)
- **SR-3** (High, phần web): Next.js ≥ 15.5.7 và React bản đã vá CVE-2025-55182 (ưu tiên bản vá mới nhất); `npm audit --audit-level=high` xanh.
- **SR-5** (High): script `dev` chạy `next dev -H 127.0.0.1`; `next.config` không có `allowedDevOrigins` wildcard. Test Vitest đọc `package.json` kiểm script `dev`.
- **SR-14** (Medium): chỉ `web/lib/env.ts` đọc `process.env`, chỉ biến `NEXT_PUBLIC_API_URL`; `next.config` không có khóa `env`. Test Vitest quét `app/`, `components/`, `lib/`.
- **SR-15** (Low, phần nền): locale từ cookie/header kiểm theo allowlist `["vi","en"]`, sai thì dùng `vi`. Test locale `xx`.
- **SR-16** (Medium): commit `package-lock.json`; `make check` dùng `npm ci`.
- **SR-19** (Low): ESLint bật `react/no-danger: error`.
