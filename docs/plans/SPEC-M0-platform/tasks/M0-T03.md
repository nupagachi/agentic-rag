## Mục tiêu
Sau task này `make dev-worker` khởi động worker, kiểm kết nối Redis, log "ready" dạng JSON và thoát gọn khi Ctrl+C.

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.3 (AC3.1–3.3), 4.6
- Kiến trúc: `docs/Kiến trúc.md` mục 3 (Python worker). Chỉ tạo package gốc, **không** tạo `runtime/`, `stages/`, `clients/`.
- Biến môi trường trong `deploy/.env.example` (M0-T01): `REDIS_URL` (hoặc `WORKER_REDIS_URL`), `WORKER_LOG_LEVEL`.
- Hợp đồng Makefile con (README): target `check`, `dev`, `sec`.
- Skill: `be-python-standards`.

## Acceptance criteria
- **AC1**: `workers/pyproject.toml` (uv, Python 3.12, package `rag_worker`), `uv.lock` commit. `uv sync` cài đủ.
- **AC2**: `python -m rag_worker` (tùy chọn `--stage <tên>` chỉ để ghi vào log, mặc định `idle`): đọc config bằng pydantic-settings (nạp `../.env` khi dev), log JSON có `ts`, `level`, `msg`, `stage`; ping Redis; log `ready`; chờ đến khi nhận SIGINT/SIGTERM thì log `shutdown` và thoát 0. (SPEC AC3.1)
- **AC3**: Given thiếu biến bắt buộc hoặc URL sai định dạng, Then thoát mã 1, thông báo nêu tên biến, không in giá trị. Redis không kết nối được sau 5 giây → log lỗi (không in URL đầy đủ có mật khẩu) và thoát 1. (SPEC AC3.2, AC6.3)
- **AC4**: Test pytest: config hợp lệ, thiếu biến, che secret; vòng chờ dừng khi nhận tín hiệu (dùng event giả, không cần Redis thật). (SPEC AC3.3)
- **AC5**: `workers/Makefile`: `check` (`uv run ruff check`, `uv run ruff format --check`, `uv run mypy --strict rag_worker`, `uv run pytest`), `dev` (`uv run watchfiles "python -m rag_worker" rag_worker`), `sec` (`uv run pip-audit`). `make check-workers` từ root xanh. (SPEC AC1.3, AC5.3)
- **AC6**: Sửa file `.py` khi `make dev-worker` đang chạy → tự khởi động lại ≤ 5 giây.
- **AC7**: Chạy được trên Windows (Git Bash): không dùng `signal.SIGTERM` handler kiểu chỉ có trên POSIX mà không có fallback; Ctrl+C phải thoát gọn.

## Yêu cầu bảo mật (từ threat model)
- **SR-7** (High): `hide_input_in_errors=True`; `__main__` bắt `ValidationError`, chỉ in `loc` + loại lỗi, thoát 1; mật khẩu/URL Redis là `SecretStr`; traceback không `show_locals`; log khởi động chỉ in config đã che. Test với sentinel `S3NTINEL`.
- **SR-16** (Medium): commit `uv.lock`; `make check` chạy `uv lock --check`; cài bằng `uv sync --frozen`.
- **SR-19** (Low): ruff chọn thêm nhóm `S` (flake8-bandit).

## Yêu cầu test
- Unit như AC4. Tích hợp với Redis thật thuộc M0-T07.
