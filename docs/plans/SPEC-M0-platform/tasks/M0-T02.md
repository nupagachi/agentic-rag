## Mục tiêu
Sau task này `make dev-api` chạy được server Go trên `127.0.0.1:8080` với `/healthz`, `/readyz` kiểm Postgres + Redis thật.

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.2 (AC2.1, 2.2, 2.3, 2.5, 2.6), 4.6
- Kiến trúc: `docs/Kiến trúc.md` mục 3 (Go API: `cmd/app/main.go`, `internal/platform/`)
- Biến môi trường đã khai báo trong `deploy/.env.example` (M0-T01): `API_ADDR`, `DATABASE_URL`, `REDIS_URL`, `LOG_LEVEL`, `CORS_ALLOWED_ORIGINS`.
- Hợp đồng Makefile con (README): target `check`, `dev`, `sec`.
- Skill: `be-go-standards`.

## Acceptance criteria
- **AC1**: `api/cmd/app/main.go` có lệnh con `app api` (dùng `flag`/subcommand đơn giản, chưa cần cobra). Lệnh lạ in usage, thoát mã 2.
- **AC2**: Given thiếu hoặc sai `DATABASE_URL`/`REDIS_URL`/`API_ADDR`, When `app api`, Then thoát mã 1, thông báo nêu đúng tên biến, không in giá trị (đặc biệt mật khẩu trong URL). Có unit test. (SPEC AC2.2)
- **AC3**: Log bằng `log/slog` JSON handler, mức theo `LOG_LEVEL`. Lúc khởi động log config đã che secret (password trong DSN thay bằng `***`). Có unit test cho hàm che. (SPEC AC6.3)
- **AC4**: `GET /healthz` → 200 `{"status":"ok"}` không kiểm phụ thuộc. `GET /readyz` → 200 `{"status":"ok"}` nếu ping Postgres và Redis đều xong trong 1 giây (chạy song song), ngược lại 503 `{"status":"unavailable","failing":["postgres"|"redis"]}`. Không trả chi tiết lỗi kết nối trong body. (SPEC AC2.3)
- **AC5**: Health checker nhận interface `Pinger` để test được không cần DB thật; unit test các trường hợp: cả hai ok, một lỗi, timeout. (SPEC AC2.6)
- **AC6**: Given SIGINT/SIGTERM, Then `http.Server.Shutdown` với timeout 10 giây, đóng pool pgx và client Redis, log "shutdown complete", thoát mã 0. (SPEC AC2.5)
- **AC7**: Server mặc định listen `127.0.0.1:8080`; đặt `ReadHeaderTimeout` (vd 5s), `IdleTimeout`. (SPEC AC2.6, AC6.1)
- **AC8**: Router chi tạo trong `internal/platform/server` với một điểm `Use(...)` để M0-T05 gắn middleware mà không sửa nhiều file (để sẵn hàm nhận `[]func(http.Handler) http.Handler`).
- **AC9**: `api/Makefile` có: `check` (gofmt -l fail nếu có file, `go vet ./...`, `golangci-lint run`, `go test ./...`), `dev` (`air` với `.air.toml`, nạp `../.env`), `sec` (`govulncheck ./...`). `make check-api` từ root xanh. (SPEC AC1.3, AC5.3)
- **AC10**: Sửa 1 file `.go` khi `make dev-api` đang chạy → tự build lại ≤ 5 giây.

## Yêu cầu bảo mật (từ threat model)
- **SR-3** (High, phần Go): `go.mod` ghi `go 1.27` (Go mới nhất, hiện 1.27.2); `govulncheck ./...` xanh.
- **SR-4** (High): mặc định `127.0.0.1:8080`; `API_ADDR` không có host (vd `":8080"`) bị từ chối, thoát 1, nêu tên biến. Test `TestConfig_DefaultAddrLoopback`, `TestConfig_AddrWithoutHost_Rejected`.
- **SR-6** (High): lỗi config chỉ nêu tên biến + lý do, không giá trị; secret/DSN dùng kiểu riêng có `String()`, `GoString()`, `LogValue()` trả `***`; lỗi kết nối pgx/go-redis khi log đi qua cùng cơ chế che. Test với sentinel `S3NTINEL` cho `%v %+v %#v` và slog JSON.
- **SR-8** (Medium): body 503 `/readyz` chỉ chứa tên phụ thuộc từ tập cố định `postgres`, `redis`; không `err.Error()`. Test `TestReadyz_FailingBodyOnlyNames`.
- **SR-12** (Medium, phần config): `CORS_ALLOWED_ORIGINS` đọc vào config ở task này; giá trị chứa `*` bị từ chối khi khởi động. Test `TestConfig_CORSWildcard_Rejected`.
- **SR-13** (Low): `http.Server` có `ReadHeaderTimeout` ≤ 10s, `ReadTimeout`, `IdleTimeout`, `MaxHeaderBytes` ≤ 64 KiB. Test `TestNewServer_Timeouts`.
- **SR-16** (Medium): commit `go.sum`; `make check` chạy `go mod verify`.
- **SR-19** (Low): `.golangci.yml` bật `gosec`, `errcheck`, `bodyclose`, `noctx`.

## Yêu cầu test
- Unit: config (thiếu biến, sai định dạng, che secret), health (Pinger giả), server shutdown (dùng `httptest`).
- Không cần testcontainers ở task này (M0-T07 làm tích hợp).
