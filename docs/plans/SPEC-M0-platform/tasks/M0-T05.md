## Mục tiêu
Sau task này mọi request vào API có request id, log access JSON, panic không làm sập server và không lộ stack, web dev gọi được API qua CORS.

## Bối cảnh và tham chiếu
- SPEC: `docs/specs/SPEC-M0-platform.md` mục 4.2 (AC2.4), 4.6
- Khung router và điểm gắn middleware: `api/internal/platform/server/` (M0-T02 AC8)
- Biến `CORS_ALLOWED_ORIGINS` đã có trong config (M0-T02).
- Skill: `be-go-standards`.

## Acceptance criteria
- **AC1**: `RequestID`: nhận `X-Request-ID` từ client nếu khớp `^[A-Za-z0-9._-]{1,64}$`, không thì sinh mới (UUID); set vào response header và context; logger trong context có `request_id`.
- **AC2**: `AccessLog`: mỗi request một dòng JSON gồm `request_id`, `method`, `route` (pattern chi, vd `/readyz`, **không** URL thật/query string), `status`, `duration_ms`, `bytes`. Không log header `Authorization`, `Cookie`, body.
- **AC3**: `Recover`: handler panic → 500 `application/json` `{"code":"INTERNAL","requestId":"…"}`; log mức error có stack; server tiếp tục phục vụ request sau.
- **AC4**: `CORS`: chỉ cho origin trong `CORS_ALLOWED_ORIGINS` (mặc định `http://localhost:3000`), method `GET, HEAD, OPTIONS` (theo SR-12), header `Content-Type, Authorization, X-Request-ID`, expose `X-Request-ID`. Origin lạ không có header `Access-Control-Allow-Origin`. Không dùng `*`.
- **AC5**: Thứ tự: RequestID → AccessLog → Recover → CORS → router. Gắn vào server qua điểm `Use` của M0-T02.
- **AC6**: Unit test từng middleware bằng `httptest` (request id hợp lệ/không hợp lệ, route pattern, panic → 500 + request kế tiếp vẫn ok, CORS origin cho phép/không cho phép, preflight).

## Yêu cầu bảo mật (từ threat model)
- **SR-9** (Medium): body 500 cố định `{"code":"INTERNAL","requestId":"…"}` (giữ định dạng AC3 để khớp problem+json về sau), không panic value/stack/đường dẫn file; stack chỉ trong log có `request_id`; không nuốt `http.ErrAbortHandler`. Test `TestRecover_NoLeak`, `TestRecover_ErrAbortHandler_Repanics`.
- **SR-10** (Medium): access log chỉ có key allowlist (`request_id`, `method`, `route`, `status`, `duration_ms`, `bytes` + `time`, `level`, `msg`); route không khớp ghi `"unmatched"`. Test với sentinel trong query, `Authorization`, `Cookie`, path.
- **SR-11** (Medium): regex `^[A-Za-z0-9._-]{1,64}$`; sai thì sinh mới. Table test: CRLF, 1000 ký tự, `<script>`, rỗng.
- **SR-12** (Medium): allowlist origin từ config (mặc định `http://localhost:3000`, `http://127.0.0.1:3000`); không phản chiếu origin tùy ý, không chấp nhận `null`, không `Allow-Credentials`; method chỉ `GET, HEAD, OPTIONS`; có `Vary: Origin`. **SR này ghi đè AC4** về danh sách method.
